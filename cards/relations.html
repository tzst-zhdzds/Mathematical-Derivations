Relations and Equivalence Relations

Binary Relations

Let A and B be sets. By Theorem 10, A × B contains all ordered pairs with first entry in A and second entry in B. Any subset R of A × B is called a binary relation from A to B.

R ⊆ A × B

To say that x is related to y means that the pair (x, y) belongs to R. We can write the same statement in either form.

x R y ⇔ (x, y) ∈ R

When both entries come from the same set A, we call R a relation on A. In this case R ⊆ A × A. The order of the entries still matters. For example, let a and b be distinct elements of A and take R = {(a, b)}. Then a R b holds. By Theorem 9, (b, a) differs from (a, b), so b R a is false.

Equivalence Relations

A relation R on A is an equivalence relation if and only if it has all three properties below.

  • Reflexive. For every x ∈ A, x R x. Each element is related to itself.
  • Symmetric. For all x, y ∈ A, if x R y, then y R x. A comparison can be reversed.
  • Transitive. For all x, y, z ∈ A, if x R y and y R z, then x R z. The two comparisons share the middle element y.

Example

Let A = {a, b, c}, where a, b, and c are distinct. For x and y in A, keep (x, y) if x = y or if both x and y belong to {a, b}. By Axiom 2, the pairs that pass this test form a subset R of A × A.

R = {(a, a), (b, b), (c, c), (a, b), (b, a)}.

  • Reflexivity holds because x = x for every x in A.
  • Symmetry holds because reversing the entries preserves both tests: equal entries remain equal, and two entries in {a, b} both remain in {a, b}.
  • For transitivity, suppose x R y and y R z. If y = c, the only pair involving c is (c, c), so x = z = c and x R z. If y belongs to {a, b}, both x and z must also belong to {a, b}, so again x R z.

Thus R is an equivalence relation on A. In particular, a R b holds even though a and b are distinct elements.
