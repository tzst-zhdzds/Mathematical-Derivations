Set Operations

Assuming set U = {1, 2, 3, 4, 5}. Pick two subset from U：

A = {1, 2, 3}，B = {3, 4}

Union

The union of A and B written as A ∪ B. The set A ∪ B contains every element that belongs to at least one of the two sets(A and B). Ex:

A ∪ B = {1, 2, 3, 4}

Also, if an element exists in A and B at the same time, then we just need to list it in A ∪ B once.

Intersection

The intersection of A and B written as A ∩ B. An element belongs to A ∩ B if and only if it belongs to both A and B. Ex:

A ∩ B = {3}

Set Difference

The set difference from A to B written as A ∖ B. A ∖ B is defined as: The set difference A ∖ B consists of the elements of A that do not belong to B. To find A ∖ B, start with A and remove every element that also belongs to B.

A ∖ B = {1, 2}

Changing the order can change the result! Ex:

B ∖ A = {4}

Complement Set

Given a set U，set A's complement set relative to U written as Ac. Ac is the set for all elements in U but not in A. Or in other word, Ac = U \ A. Ex:

Ac = U ∖ A = {4, 5}

Symmetric Difference

The symmetric difference set of A and B written as A △ B. It contains the elements that belong to exactly one of the two sets. Ex:

A △ B = {1, 2, 4}

A ∖ B contains the elements that belong only to A. B ∖ A contains the elements that belong only to B. Taking their union gives the symmetric difference:

A △ B = (A ∖ B) ∪ (B ∖ A)
