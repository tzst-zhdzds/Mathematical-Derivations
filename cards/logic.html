Basic Logic

Statements and Truth Values

A statement is a sentence that can be true or false. Example: The sentence "The box is locked" is a statement. It has a truth value even if we have not checked the box yet.

We can use letters as short names for statements. For the box example, let P mean "The box is locked" and Q mean "The light is on."

Not, And, and Or

  • ¬P means "not P." In our example, it says that the box is not locked. It is true exactly when P is false.
  • P ∧ Q means "P and Q." It is true exactly when the box is locked and the light is on.
  • P ∨ Q means "P or Q." It is true when the box is locked, the light is on, or both. In mathematics, "or" includes the case where both statements are true.

If P, Then Q

P ⇒ Q

Read this as "if P, then Q" or "P implies Q." In our example, the claim is that whenever the box is locked, the light is on. What observation would show that the claim is false?

We would have to find the box locked and the light off. That is the only case where P is true and Q is false. If the box is unlocked, the claim places no requirement on the light. In classical logic, the implication is true in both unlocked cases.

We can now answer the opening question. Knowing P ⇒ Q and P lets us conclude Q. But if all we know is P ⇒ Q and the light is on, the box could still be unlocked.

If and Only If

P ⇔ Q

Read this as "P if and only if Q," often shortened to "P iff Q." It says that both directions hold.

  • P ⇒ Q. If the box is locked, the light is on.
  • Q ⇒ P. If the light is on, the box is locked.

Now the light alone tells us whether the box is locked. To prove an "if and only if" statement, we must justify both directions. The table below shows how this differs from proving one implication.

For Every and There Exists

Imagine a tray of keys and a particular door. Let x stand for any key on the tray. Write P(x) for the condition "x opens the door." The answer can change with the key we put in place of x. Such a condition is called a predicate.

∀x P(x)

The symbol ∀ means "for every." Here the statement says that every key on the tray opens the door. A single key that fails to open it would make this statement false. Such a key would be a counterexample.

∃x P(x)

The symbol ∃ means "there exists at least one." Here the statement says that some key on the tray opens the door. To prove it, we could show that the brass key opens the door. The brass key would be a witness. Other keys may open the door too.

Meaning of "For all x" in the Proof

Suppose our goal is ∀x P(x). We begin, "Let x be any key on the tray." We may use facts that hold for every key under discussion. If those facts let us prove P(x), the argument works whichever key x stands for. This is why we can conclude ∀x P(x).

If our argument uses a special fact about the brass key, it proves something about that key. That can be enough for ∃x P(x). To conclude ∀x P(x), we also need a reason the argument covers every other key.

Negate a Quantified Statement

"Not every key opens the door" means that at least one key fails. "No key opens the door" means that every key fails. In symbols, these are two different claims:

¬(∀x P(x)) ⇔ ∃x ¬P(x)

¬(∃x P(x)) ⇔ ∀x ¬P(x)

Why the Order of Quantifiers Matters

Imagine a front door and a back door. The brass key opens only the front door. The silver key opens only the back door. These are the only doors and keys in our example.

Consider these two statements.

  1. Every door has a key that opens it.
  2. There is a key that opens every door.

The first statement is true. If you point to the front door, I can show you the brass key. If you point to the back door, I can show you the silver key. My answer can depend on which door you point to.

The second statement is false. This time I have to name a key first. If I name the brass key, it fails at the back door. If I name the silver key, it fails at the front door.

Now let d stand for a door and k stand for a key. We can shorten each sentence by writing just its quantifiers in symbols. Read from left to right.

∀d ∃k [k opens d]

For every door d, there is a key k that opens d.

∃k ∀d [k opens d]

There is a key k such that, for every door d, that key opens d.
