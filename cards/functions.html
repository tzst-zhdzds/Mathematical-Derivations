Functions

Definition

A function from set A to set B is a binary relation that pairs each element of A with exactly one element of B. We write f: A → B.

Set A is called the domain, and B is called the codomain. For an input x in A, we write f(x) = y when (x, y) belongs to the relation f.

f(x) = y ⇔ (x, y) ∈ f

To decide whether a relation from A to B is a function, check each input x in A:

  1. For every element x belongs to set A must appear as the first term of at least one ordered pair.
  2. Each input has at most one output. Ex: you can't have (x, y) and (x, z) belongs to f when y ≠ z.

Example

Let A be a set of fruit names and B a set of letters. Define f by assigning each name its first letter.

A = {apple, apricot, banana}

B = {a, b}

Written as a set of ordered pairs, the function is

f = {(apple, a), (apricot, a), (banana, b)}.

For example, the pair (apple, a) tells us that f(apple) = a. We also have f(apricot) = a. Two different inputs can share an output. Each input still has exactly one output.

Keep the same sets A and B. What happens if we remove (banana, b) from f? The resulting relation is

R = {(apple, a), (apricot, a)}.

The name banana still belongs to A, but it has no output in R. So R is not a function from A to B.

Now start again with f and add the pair (apple, b). The resulting relation is

S = {(apple, a), (apple, b), (apricot, a), (banana, b)}.

Every input has an output, but apple has two different outputs, a and b. So S is not a function from A to B.
