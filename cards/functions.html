Functions

One Output for Each Input

Let A and B be sets. By Theorem 10, the Cartesian product A × B is the set of all ordered pairs (x, y) with x ∈ A and y ∈ B. Think of x as an input and y as a possible output.

Choose a subset of A × B and call it R. Its elements are ordered pairs. We call such a subset a relation from A to B. Writing (x, y) ∈ R means that we included the pair (x, y) in our selection.

A function from A to B is a relation f with one additional requirement. For every input x ∈ A, there must be exactly one output y ∈ B such that (x, y) ∈ f.

f: A → B

We call A the domain and B the codomain. For each input x ∈ A, we write f(x) for its unique output. The set of all the input-output pairs is called the graph of the function. Here we represent a function by its graph.

f(x) = y ⇔ (x, y) ∈ f

Reading a Function from Its Pairs

Let A = B = {0, 1}. Consider the following set of pairs.

f = {(0, 1), (1, 1)}

To find f(0), look for the pair whose first entry is 0. That pair is (0, 1), so f(0) = 1. The pair starting with 1 is (1, 1), so f(1) = 1 as well.

Both inputs have the same output. This is allowed because each input still has exactly one output. The value 0 belongs to the codomain even though no input has 0 as its output.

Keeping the same domain and codomain, we can see why both parts of "exactly one" matter.

  • If we remove (1, 1), only (0, 1) remains. The input 1 now has no output, so the remaining pairs do not define a function from A to B.
  • If we instead add (0, 0) to the original graph, then both (0, 1) and (0, 0) appear. The input 0 now has two different outputs, so this graph also fails to define a function from A to B.

Theorem 11: A Rule Determines a Function

Fix sets A and B. Let R(x, y) stand for a condition on x and y written in the language of set theory. Suppose that for each x ∈ A, exactly one y ∈ B satisfies this condition. Then there is a unique function f: A → B such that, for all x ∈ A and y ∈ B,

f(x) = y ⇔ R(x, y).

Proof. Start with A × B. By Theorem 9, each ordered pair has a uniquely determined first entry x and second entry y. We can therefore test whether R(x, y) holds for that pair. By Axiom 2, the pairs that pass this test form a set. Call it f.

Why does every input have an output? Fix x ∈ A. By our assumption, some y ∈ B satisfies R(x, y). The pair (x, y) belongs to A × B and passes the test, so (x, y) ∈ f.

Why is that output unique? Suppose (x, z) also belongs to f. Then R(x, z) holds. Our assumption says that exactly one element of B satisfies the condition for this x. Since y and z both satisfy it, z = y. Thus f is a function from A to B.

Finally, suppose g: A → B satisfies the same rule. A pair (x, y) belongs to g exactly when R(x, y) holds, which is exactly when it belongs to f. The graphs contain the same pairs, so by Axiom 1, f = g.

The Successor Function

Take A = B = ℕ and use the condition y = S(n). For each natural number n, the definition S(n) = n ∪ {n} gives one particular set. By Theorem 6, ℕ is inductive, so this set belongs to ℕ.

Thus each input n ∈ ℕ has exactly one output in ℕ. By Theorem 11, the pairs (n, S(n)) form the graph of a function. We call it the successor function.

S: ℕ → ℕ

For example, (0, 1) belongs to its graph because S(0) = 1, and (1, 2) belongs to its graph because S(1) = 2.
