The Set of Natural Numbers

Recall: In Natural Numbers, we started with 0 = ∅ and used the rule S(x) = x ∪ {x} to build each successor.

Inductive Sets

A set I is called inductive if it satisfies both conditions:

  1. 0 ∈ I.
  2. For every x ∈ I, its successor S(x) also belongs to I.

For example, consider the set {0, 1, 2}. It contains 0. It also contains S(0) = 1 and S(1) = 2. But when we reach 2, the rule requires S(2) = 3 to be in the set as well. Since 3 ∉ {0, 1, 2}, this set is not inductive.

The Axiom of Infinity

The Axiom of Infinity states that at least one inductive set exists. Choose such a set and call it I.

We know that 0 ∈ I. Applying the successor condition to 0 gives 1 ∈ I. Applying it to 1 gives 2 ∈ I, and applying it to 2 gives 3 ∈ I. Each number we reach by repeating this process belongs to I.

Could I contain extra elements? Yes. The two conditions tell us what I must contain, but they allow other elements as well. To define the natural numbers, we keep only the elements that every inductive set must contain.

The Smallest Inductive Set

From our chosen set I, form a subset N by the following rule: keep an element x exactly when x belongs to every inductive set.

N = {x ∈ I | x belongs to every inductive set}

Claim that N is the smallest inductive set. Here, "smallest" means that N is itself inductive and is a subset of every inductive set.

Proof: First, check the two conditions for N to be inductive.

  1. N contains 0. Every inductive set contains 0, including I. Therefore, 0 passes the rule for membership in N.
  2. N contains the successor of each of its elements. Suppose x ∈ N. We want to show that S(x) ∈ N. Pick any inductive set J. Since x ∈ N, we know that x ∈ J. Since J is inductive, S(x) ∈ J as well. This works for every inductive set J, including I. Therefore, S(x) ∈ N.

These two conditions show that N is inductive. Now take any inductive set J. By the rule defining N, every element of N belongs to J. Thus N ⊆ J, which proves the claim.

We call this smallest inductive set the set of natural numbers and write it as ℕ. In our construction, 0 is a natural number.

ℕ = {0, 1, 2, 3, ...}
