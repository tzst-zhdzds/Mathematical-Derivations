Natural Numbers Inside the Integers

In our construction of the natural numbers, 2 is the set {0, 1}. In our construction of the integers, two forward steps give the record (2, 0), and its class [(2, 0)] is an integer. Why can we use the same numeral 2 in both settings?

Sending a Natural Number to an Integer

For each natural number n, take n forward steps and zero backward steps. The record (n, 0) belongs to ℕ × ℕ, so its class [(n, 0)] belongs to ℤ. This rule assigns exactly one integer to each n. By Theorem 11, it defines a function. We call it ι, the Greek letter iota.

ι: ℕ → ℤ

ι(n) = [(n, 0)].

For example, ι(2) is the entire class [(2, 0)]. Does this class also contain the record (3, 1)? The equivalence test asks whether 2 + 1 = 3 + 0. Both sums equal 3, so it does.

(3, 1) ∈ ι(2) and [(3, 1)] = ι(2).

The first statement names one record in the class. The second names the whole integer using that record as its representative.

Theorem 34: The Natural Numbers Embed in the Integers

Here an embedding means that distinct natural numbers have distinct images and that the map preserves addition and multiplication. For all m and n in ℕ, we claim:

ι(m) = ι(n) ⇔ m = n.

ι(m + n) = ι(m) + ι(n).

ι(m · n) = ι(m) · ι(n).

In the last two formulas, the operation on the left is performed in ℕ before applying ι. On the right, we first apply ι to each input and then perform the operation in ℤ.

Proof of Theorem 34

First compare the outputs. By Theorem 26, [(m, 0)] and [(n, 0)] are equal exactly when (m, 0) and (n, 0) are equivalent. Applying the test for these two records gives

ι(m) = ι(n) ⇔ m + 0 = n + 0 ⇔ m = n.

The last step uses Theorem 13. Thus each natural number can be recovered uniquely from its image.

For addition, start on the integer side. By Theorem 27, add the forward counts and add the backward counts:

ι(m) + ι(n) = [(m + n, 0 + 0)] = [(m + n, 0)] = ι(m + n).

For multiplication, use Theorem 29. Substitute (m, 0) and (n, 0) for the two records:

ι(m) · ι(n) = [(m · n + 0 · 0, 0 · n + m · 0)].

By Theorem 19, each product involving 0 is 0. The record becomes (m · n + 0, 0 + 0), which simplifies to (m · n, 0). Its class is ι(m · n). This proves the third claim.

Why We Can Write the Same Numerals

The integers of the form ι(n) make up a subset of ℤ. By Axiom 2, we can form it by keeping an integer z exactly when z = ι(n) for some n ∈ ℕ. This subset is called the image of ι.

For instance, ι(0) = [(0, 0)] = 0ℤ and ι(1) = [(1, 0)] = 1ℤ. More generally, when we write a natural numeral such as 2 in an integer calculation, it stands for ι(2). By Theorem 34, adding or multiplying these numerals gives the same answer whether we do the arithmetic before or after applying ι. This is the sense in which ℕ sits inside ℤ.
