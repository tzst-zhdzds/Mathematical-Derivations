Empty Set

A set with no elements is defined as the empty set, written as ∅，or {}。

Note: ∅ has 0 elements, but {∅} have one，which is the empty set itself. so:

∅ ≠ {∅}

The empty set ∅ is a subset of all sets

So assume we have a set A, want to prove:

∅ ⊆ A

Proof: Based on Definition of the subsets. if ∅ is not a subset of A，there at least exist one element x such that x ∈ ∅ and x ∉ A.

But empty set does not have any elements! So no such x. Contradiction! So ∅ ⊆ A.
