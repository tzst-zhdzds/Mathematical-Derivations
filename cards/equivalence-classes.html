Equivalence Classes and Partitions

Equivalence Classes

Let R be an equivalence relation on a set A. Pick an element a in A. Which elements of A are related to a?

The set of all such elements is called the equivalence class of a, written as [a].

[a] = {x ∈ A | a R x}

The vertical bar means "such that". To decide whether x belongs to [a], we check whether a R x.

Example

Let A be the following set of fruit names.

A = {apple, apricot, banana, blueberry}

For any x and y in A, let x R y mean that x and y start with the same letter.

This is an equivalence relation on A.

  • Reflexive. Every name starts with the same letter as itself.
  • Symmetric. If x starts with the same letter as y, then y starts with the same letter as x.
  • Transitive. Suppose x R y and y R z. Then x and z both start with the first letter of y, so x R z.

What is [apple]? Start with apple and look for every name in A that begins with the letter "a". We find apple itself and apricot.

[apple] = {apple, apricot}

What if we start with apricot instead? We look for names beginning with "a" again, so we get exactly the same set.

[apricot] = [apple]

Starting with banana or blueberry gives the other class. Both names begin with "b".

[banana] = [blueberry] = {banana, blueberry}

Partitions

A partition of A is a collection of nonempty subsets of A such that each element of A belongs to exactly one of those subsets.

In our fruit example, each name belongs to exactly one of the two classes. These classes form the following partition of A.

{{apple, apricot}, {banana, blueberry}}

Theorem: Equivalence Classes Form a Partition

Let R be an equivalence relation on A. The collection of all distinct equivalence classes of R is a partition of A.

Proof: Every Element Belongs to Exactly One Class

Pick any a ∈ A. By definition, [a] contains every x ∈ A for which a R x. Taking x = a, we have a R a by reflexivity, so a ∈ [a]. Thus every element belongs to at least one class, and each class [a] contains at least the element a.

Suppose [a] and [b] share an element z. Since z ∈ [a], we have a R z. Since z ∈ [b], we have b R z. By symmetry, z R b. Now a R z and z R b give a R b by transitivity. By symmetry again, b R a.

We can now compare [a] and [b] using subsets.

  • To show [a] ⊆ [b], pick any x ∈ [a]. Then a R x. Since b R a and a R x, transitivity gives b R x. Thus x ∈ [b].
  • To show [b] ⊆ [a], pick any x ∈ [b]. Then b R x. Since a R b and b R x, transitivity gives a R x. Thus x ∈ [a].

Each class is a subset of the other, so [a] = [b]. Therefore, two distinct classes cannot share an element.

Every element of A belongs to its own class, and two distinct classes cannot share an element. Therefore, each element belongs to exactly one class. Since each class is nonempty, the distinct equivalence classes form a partition of A.
