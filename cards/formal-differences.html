Additive Cancellation and Formal Differences

Imagine taking one step backward. And in another situation imagine taking one step forward and two steps backward. Starting from the same place, both walks end at the same place. We can record them as (0, 1) and (1, 2), with forward steps first and backward steps second. How can we tell when two such records describe the same change using only addition of natural numbers?

Theorem 24: Additive Cancellation

We will need to remove a common addend from an equality. For all natural numbers a, b, and d,

If a + d = b + d, then a = b.

Proof. Fix a and b. Use Theorem 7 to induct on the common addend d. The statement we are proving at each d is the entire implication above.

Base case. Suppose a + 0 = b + 0. By Theorem 13, the left side equals a and the right side equals b. Thus a = b.

Induction step. Assume that a + d = b + d implies a = b. To prove the implication at S(d), suppose

a + S(d) = b + S(d).

By Theorem 13, this says S(a + d) = S(b + d). By Theorem 8, this successor has only one predecessor. Therefore a + d = b + d. This is exactly the condition in our induction hypothesis, which now gives a = b.

A common addend on the left can also be cancelled. If d + a = d + b, then Theorem 16 gives a + d = b + d, so the result just proved gives a = b.

Comparing Two Formal Differences

Let D = ℕ × ℕ. We use a pair (a, b) in D as a formal difference: a records forward steps and b records backward steps. Adding the same number of forward and backward steps to a walk leaves its endpoint unchanged.

To compare (a, b) with (c, d), give the first walk d extra steps in each direction and the second walk b extra steps in each direction. Their backward counts are now b + d and d + b, which are equal by Theorem 16. Their forward counts are a + d and c + b. This suggests the following definition.

(a, b) ∼ (c, d) ⇔ a + d = c + b.

Read ∼ as "is equivalent to". For the opening example, (0, 1) ∼ (1, 2) because 0 + 2 = 1 + 1. Both sums equal 2. The ordered pairs themselves are distinct by Theorem 9, since their first entries differ.

This definition gives a relation on D. Indeed, D × D exists by Theorem 10. By Axiom 2, we can select exactly those pairs of records that pass the displayed test.

Theorem 25: Equivalence of Formal Differences

A relation is called an equivalence relation when it has three properties: every record is related to itself (reflexivity), a comparison can be reversed (symmetry), and two comparisons can be chained (transitivity). We claim that ∼ has all three properties.

Reflexivity. To check (a, b) ∼ (a, b), the definition asks whether a + b = a + b. This holds for every pair (a, b).

Symmetry. Suppose (a, b) ∼ (c, d). Then a + d = c + b. Reading the equality in reverse gives c + b = a + d, exactly the condition for (c, d) ∼ (a, b).

Transitivity. Suppose (a, b) ∼ (c, d) and (c, d) ∼ (e, f). Writing out these two assumptions gives

a + d = c + b

c + f = e + d

Our goal is (a, b) ∼ (e, f), which means a + f = e + b. The first assumption tells us something about a + d, but our goal contains a + f. To bring d into the calculation, consider (a + f) + d. We can cancel d at the end by Theorem 24.

We will exchange the last two terms of a sum several times. This is allowed by Theorem 17 for regrouping and Theorem 16 for exchanging two addends:

(x + y) + z = x + (y + z) = x + (z + y) = (x + z) + y.

  1. Start with (a + f) + d. Exchange f and d to get (a + d) + f. The first assumption replaces a + d with c + b, giving (c + b) + f.
  2. Exchange b and f to get (c + f) + b. The second assumption replaces c + f with e + d, giving (e + d) + b.
  3. Exchange d and b to get (e + b) + d.

We have proved

(a + f) + d = (e + b) + d.

By Theorem 24, a + f = e + b. Thus (a, b) ∼ (e, f). This proves transitivity and completes the proof.

We now have a test for deciding which pairs belong together. On the next card, we will collect all pairs equivalent to a given pair into one set. That set will represent one integer.
