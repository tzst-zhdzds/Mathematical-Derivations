Integers

Different Records of the Same Change

One step backward gives the record (0, 1). One step forward followed by two steps backward gives (1, 2). Starting at the same place, both walks end at the same place. How can we give their shared change a single name?

Let D = ℕ × ℕ, the set of all such records. Recall the test for two records to be equivalent:

(a, b) ∼ (c, d) ⇔ a + d = c + b.

For (0, 1) and (1, 2), the test asks whether 0 + 2 = 1 + 1. Both sums equal 2, so (0, 1) ∼ (1, 2). By Theorem 25, ∼ is an equivalence relation on D.

The Equivalence Class of a Record

Fix a record p in D. Here p stands for a whole ordered pair. From D, keep each record r for which p ∼ r. By Axiom 2, these records form a set. We call it the equivalence class of p and write [p].

[p] = {r ∈ D | p ∼ r}.

The bar means "such that". For example, to decide whether (m, n) belongs to [(0, 1)], put (0, 1) on the left of the test and (m, n) on the right. The test becomes 0 + n = m + 1. By Theorem 14, 0 + n = n. So this class contains exactly the records with one more backward step than forward steps.

Theorem 26: When Two Classes Are Equal

For any records p and q in D,

[p] = [q] ⇔ p ∼ q.

First suppose [p] = [q]. By reflexivity, q ∼ q, so q belongs to [q]. Since [q] = [p], we also have q ∈ [p]. By the definition of [p], this means p ∼ q.

Conversely, suppose p ∼ q. To prove [p] = [q], we compare their elements in both directions.

  • Take any r ∈ [p]. Then p ∼ r. By symmetry, p ∼ q gives q ∼ p. By transitivity, q ∼ p and p ∼ r give q ∼ r. Thus r ∈ [q], proving [p] ⊆ [q].
  • Take any r ∈ [q]. Then q ∼ r. By transitivity, p ∼ q and q ∼ r give p ∼ r. Thus r ∈ [p], proving [q] ⊆ [p].

By Theorem 2, the two inclusions give [p] = [q]. This proves both directions.

The Set of Integers

We define an integer to be an equivalence class of records in D under ∼. How can we collect all these classes into one set? Every class [p] is a subset of D. By Axiom 5, the power set P(D) exists, and every class [p] is one of its elements.

From P(D), keep a set C exactly when C = [p] for some p ∈ D. By Axiom 2, the selected sets form a set. By Axiom 1, those elements determine it uniquely. We call it the set of integers and write ℤ.

ℤ = {C ∈ P(D) | there exists p ∈ D with C = [p]}.

We can now name the change in our opening example. We write -1 for the integer [(0, 1)]. Since (0, 1) ∼ (1, 2), Theorem 26 gives

[(0, 1)] = [(1, 2)] = -1.

The pair (1, 2) is one record in this class. The brackets in [(1, 2)] name the entire class, which is one element of ℤ.
