Union and Intersection

Union

Given sets A and B, we want a set containing everything that belongs to A, to B, or to both. How do we know such a set exists?

By Axiom 3, we can form {A, B}. Now apply Axiom 4 to {A, B}. It gives us a set containing exactly the elements that belong to some member of {A, B}. Since the members are A and B, this means precisely that an element belongs to A or to B.

By Axiom 1, these elements determine a unique set. We call it the union of A and B and write A ∪ B.

x ∈ A ∪ B ⇔ (x ∈ A ∨ x ∈ B)

Intersection

Suppose we want to keep only the elements that A and B share. Start with A. For each element x of A, the condition for keeping it is x ∈ B.

By Axiom 2, the elements of A that pass this test form a set. By Axiom 1, this set is unique. We call it the intersection of A and B and write A ∩ B.

x ∈ A ∩ B ⇔ (x ∈ A ∧ x ∈ B)

Example

Let a, b, and c be three distinct sets. Take A = {a, b} and B = {b, c}. The element a belongs only to A, the element c belongs only to B, and b belongs to both.

A ∪ B = {a, b, c}

A ∩ B = {b}

Both operations keep b. The union also keeps a and c because belonging to either set is enough.

Theorem 5: Union and Intersection of Nested Sets

For any sets A and B, if A ⊆ B, then both equalities hold.

A ∩ B = A

A ∪ B = B

Proof. Assume A ⊆ B. By the definition of a subset, whenever x belongs to A, it also belongs to B.

First consider A ∩ B. Every element of A ∩ B belongs to A, so A ∩ B ⊆ A. For the reverse inclusion, take any x ∈ A. Our assumption gives x ∈ B as well. Since x belongs to both sets, x ∈ A ∩ B. This proves A ⊆ A ∩ B. By Theorem 2, A ∩ B = A.

Now consider A ∪ B. Every element of B belongs to the union, so B ⊆ A ∪ B. For the reverse inclusion, take any x ∈ A ∪ B. Then x ∈ A or x ∈ B. If x ∈ A, our assumption gives x ∈ B. If x ∈ B, we already have what we need. In either case x ∈ B, so A ∪ B ⊆ B. By Theorem 2, A ∪ B = B.
