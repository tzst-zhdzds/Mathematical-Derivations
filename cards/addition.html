Addition on the Natural Numbers

Starting at a Number and Taking Successors

Start at 1. Before taking any steps, we are at 1. After one successor step, we are at S(1) = 2. After another step, we are at S(2) = 3. This is the idea we want the expression 1 + 2 to capture: start at 1 and take two successor steps.

More generally, in a + b, the first number a tells us where to start. The second number b tells us how many successor steps to take. We can make this precise using Theorem 12.

Theorem 13: Existence and Uniqueness of Addition

A binary operation on ℕ is a function from ℕ × ℕ to ℕ. Its input is an ordered pair of natural numbers, and its output is one natural number.

There is a unique binary operation on ℕ, called addition, whose output at (a, b) is written a + b and which satisfies the following equations for all natural numbers a and b.

a + 0 = a

a + S(b) = S(a + b)

Proof. First fix the starting number a. We want a function h whose input b counts the steps and whose output h(b) records where we end up. In Theorem 12, make the following choices.

  • The set of possible outputs is X = ℕ.
  • The starting value is a.
  • The update function is the successor function S: ℕ → ℕ.

Theorem 12 now gives exactly one function h: ℕ → ℕ satisfying these two equations:

h(0) = a

h(S(b)) = S(h(b))

Why are there two occurrences of S in the second equation? On the left, S(b) advances the step count. On the right, S(h(b)) advances the current value. For example, if we start at 1 and have taken zero steps, the step count is 0 while the current value is 1.

Now allow a to vary as well. Given any pair (a, b), use a to determine the function h above, then take its value at b. This rule gives exactly one natural number for each pair: the starting value determines a unique h, and h gives a unique output at b. By Theorem 11, the rule defines a function from ℕ × ℕ to ℕ.

Write its output as a + b. For our fixed starting value a, this means h(b) = a + b. Substituting this notation into h(0) = a gives a + 0 = a. In the step equation, h(S(b)) becomes a + S(b), and S(h(b)) becomes S(a + b). This gives the second equation:

a + S(b) = S(a + b).

Finally, suppose another binary operation satisfies the same two equations. Fix its first input a and let the second input b vary. The resulting function of b starts at a and applies S at each step. By the uniqueness in Theorem 12, it must be h. Thus the two operations give the same output for every pair (a, b). Their graphs are equal by Axiom 1.

Computing 1 + 2

Keep the first input fixed at 1. The starting equation gives 1 + 0 = 1. To find 1 + 1, write the second input as S(0) and use the step equation with a = 1 and b = 0.

1 + 1 = 1 + S(0) = S(1 + 0) = S(1) = 2.

Now use the same equation with a = 1 and b = 1. Since 2 = S(1), we get

1 + 2 = 1 + S(1) = S(1 + 1) = S(2) = 3.

Theorem 14: Zero on the Left

The starting equation tells us what happens when the second input is 0. What happens when the first input is 0? For every natural number b, we claim that

0 + b = b.

Proof. Use Theorem 7 to induct on b.

Base case. Let b = 0. The starting equation from Theorem 13 says a + 0 = a. Taking a = 0 gives 0 + 0 = 0.

Induction step. Assume 0 + b = b. Our goal is to prove the statement at the next input, namely 0 + S(b) = S(b). The step equation from Theorem 13, with a = 0, gives

0 + S(b) = S(0 + b).

Inside the outer S, the induction hypothesis lets us replace 0 + b with b. Thus S(0 + b) = S(b), as required. By induction, 0 + b = b for every b ∈ ℕ.
