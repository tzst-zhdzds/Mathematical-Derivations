Addition of Natural Numbers

In Recursion on the Natural Numbers, we built a function that started at 2 and took the successor of its output at each step. What happens if we start at any natural number a and follow the same rule?

Definition

Fix a natural number a. By the recursion theorem, there is a unique function f: ℕ → ℕ with starting value f(0) = a and step rule f(S(n)) = S(f(n)). We call f(n) the sum of a and n, written as a + n.

In this notation, the two rules become:

a + 0 = a

a + S(n) = S(a + n)

The first rule gives the starting value. The second tells us how to use a sum we already know: if we know a + n, its successor is a + S(n). The first number a stays fixed throughout.

Example

Fix a = 2. The starting rule gives

2 + 0 = 2.

Since 1 = S(0), we can use the step rule with n = 0:

2 + 1 = 2 + S(0) = S(2 + 0) = S(2) = 3.

Now use the same rule with n = 1. This time we know that 2 + 1 = 3:

2 + 2 = 2 + S(1) = S(2 + 1) = S(3) = 4.

Theorem: Adding Zero on the Left

Our starting rule gives n + 0 = n for every natural number n. What about 0 + n? Here n is the second input, so we can follow the recursive definition and prove the result by mathematical induction.

For every n ∈ ℕ, 0 + n = n.

Base case. Take a = 0 in the starting rule a + 0 = a. This gives 0 + 0 = 0.

Inductive step. Fix n ∈ ℕ and assume 0 + n = n. We want to prove 0 + S(n) = S(n). Apply the step rule with a = 0:

0 + S(n) = S(0 + n).

By the induction hypothesis, the expression 0 + n inside the parentheses equals n. Substituting n gives

S(0 + n) = S(n).

Combining the two equalities gives 0 + S(n) = S(n). By induction, 0 + n = n for every natural number n.
