De Morgan’s Laws

Let set A and set B be subsets of a set U. All complements are taken relative to U.

The Complement of a Union

(A ∪ B)c = Ac ∩ Bc

Proof: Let x be any element of U.

By the definition of complement, x belongs to (A ∪ B)c if and only if x does not belong to A ∪ B.

The union A ∪ B contains every element that belongs to A, to B, or to both. Therefore, x lies outside A ∪ B if and only if it belongs to neither A nor B.

This means that x belongs to both Ac and Bc, which is exactly the condition for x to belong to their intersection. Thus, for every x ∈ U,

x ∈ (A ∪ B)c ⇔ x ∈ Ac ∩ Bc.

The symbol ⇔ means “if and only if.” Each side implies the other.

The two sets contain exactly the same elements. By the definition of set equality, they are equal.

The Complement of an Intersection

(A ∩ B)c = Ac ∪ Bc

Proof. Let x be any element of U.

By the definition of complement, x belongs to (A ∩ B)c if and only if x does not belong to A ∩ B.

An element belongs to A ∩ B exactly when it belongs to both sets. Therefore, x lies outside the intersection exactly when at least one of the two sets does not contain x.

Equivalently, x belongs to Ac, to Bc, or to both. This is precisely the condition for x to belong to their union. Thus, for every x ∈ U,

x ∈ (A ∩ B)c ⇔ x ∈ Ac ∪ Bc.

The two sets contain exactly the same elements, so they are equal.
