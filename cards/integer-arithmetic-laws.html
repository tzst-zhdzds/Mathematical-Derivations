Laws of Integer Arithmetic

Let x = [(a, b)], y = [(c, d)], and z = [(e, f)] be any integers. We can choose any records for them by Theorem 27 and Theorem 29. To prove two calculations give the same integer, it is enough to show they give identical forward and backward counts.

Inside a record, ac means the natural-number product a · c. Between integers, xy means the integer product x · y.

Theorem 30: Commutativity and Associativity of Integer Addition

x + y = y + x

(x + y) + z = x + (y + z)

Proof. The records for x + y and y + x are (a + c, b + d) and (c + a, d + b). Their entries agree by Theorem 16. For associativity, apply the addition rule twice:

(x + y) + z = [((a + c) + e, (b + d) + f)].

x + (y + z) = [(a + (c + e), b + (d + f))].

By Theorem 17, the forward counts are equal, and so are the backward counts. This proves the second equality.

Theorem 31: Integer Multiplication Is Commutative and Has an Identity

xy = yx and x · 1ℤ = 1ℤ · x = x.

Proof. The product rule gives xy = [(ac + bd, bc + ad)] and yx = [(ca + db, da + cb)]. By Theorem 21, ca + db = ac + bd and da + cb = ad + bc. By Theorem 16, ad + bc = bc + ad. Both entries agree, so xy = yx.

Recall that 1ℤ = [(1, 0)]. Substituting (1, 0) for the second record gives

x · 1ℤ = [(a · 1 + b · 0, b · 1 + a · 0)] = [(a + 0, b + 0)] = x.

The simplifications use Theorem 19 and Theorem 13. Commutativity now gives 1ℤ · x = x as well.

Theorem 32: Integer Multiplication Distributes over Addition

x(y + z) = xy + xz and (y + z)x = yx + zx.

Proof. Since y + z = [(c + e, d + f)], the forward count in x(y + z) is a(c + e) + b(d + f). Expand using Theorem 22. Then use Theorem 16 and Theorem 17 to group the terms from xy together and the terms from xz together:

a(c + e) + b(d + f) = (ac + ae) + (bd + bf) = (ac + bd) + (ae + bf).

The backward count works in the same way:

b(c + e) + a(d + f) = (bc + be) + (ad + af) = (bc + ad) + (be + af).

The product xy has record (ac + bd, bc + ad), and xz has record (ae + bf, be + af). The two counts we just obtained are exactly the entries of their sum. Thus x(y + z) = xy + xz. By Theorem 31, we can put the factor x on the other side:

(y + z)x = x(y + z) = xy + xz = yx + zx.

Theorem 33: Integer Multiplication Is Associative

(xy)z = x(yz).

Proof. First compute the inner products. For the left side we need xy, and for the right side we need yz:

xy = [(ac + bd, bc + ad)].

yz = [(ce + df, de + cf)].

Compare the forward counts first. For (xy)z, multiply the forward count of xy by e and its backward count by f, then add. For x(yz), use a and b with the two counts of yz. Expand by Theorem 20 and Theorem 22. In these counts, ace abbreviates (ac)e = a(ce) by the natural-number law, Theorem 23.

Forward in (xy)z: (ac + bd)e + (bc + ad)f = ace + bde + bcf + adf.

Forward in x(yz): a(ce + df) + b(de + cf) = ace + adf + bde + bcf.

These sums have the same four terms. Moving adf from the last position to the second turns the first sum into the second. Now compare the backward counts:

Backward in (xy)z: (bc + ad)e + (ac + bd)f = bce + ade + acf + bdf.

Backward in x(yz): b(ce + df) + a(de + cf) = bce + bdf + ade + acf.

This time, move bdf from the last position to the second. Both rearrangements use Theorem 16 and Theorem 17 on natural numbers. The records agree in both entries, proving (xy)z = x(yz).
