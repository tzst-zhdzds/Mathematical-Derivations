Multiplication of Natural Numbers

Definition

Fix a natural number a. Start with a total of 0 and add a at each step. After b steps, we call the total the product of a and b, written as a · b.

We define multiplication using addition and two rules. The first rule gives the starting value. After zero steps, the total is still 0.

a · 0 = 0

The second rule tells us how to take one more step. Suppose the current total is a · b. To get the total at the next step, add a once more. Since S(b) is the successor of b, we write

a · S(b) = (a · b) + a

For each fixed a, the recursion theorem guarantees that these two rules determine exactly one value of a · b for every natural number b.

Example

What is 3 · 2? Here a = 3, so each step adds 3. We start with the first rule.

3 · 0 = 0

For the first step, take b = 0 in the second rule. Since S(0) = 1, we get

3 · 1 = (3 · 0) + 3 = 0 + 3 = 3.

For the next step, take b = 1. Since S(1) = 2, we can use the value of 3 · 1 that we just found.

3 · 2 = (3 · 1) + 3 = 3 + 3 = 6.

In 3 · 2, the first number tells us what to add each time. The second number tells us how many times to add it.
