Multiplication on the Natural Numbers

Repeated Addition

Imagine starting with a total of 0 and adding 2 at each step. Before the first step, the total is 0. After one step, it is 0 + 2. After another step, it is (0 + 2) + 2.

We write a · b for the total obtained by starting at 0 and adding a at each of b steps. The first input tells us what to add at each step. The second input counts the steps.

Theorem 18: Existence and Uniqueness of Multiplication

There is a unique binary operation on ℕ, called multiplication, whose output at (a, b) is written a · b and which satisfies the following equations for all natural numbers a and b.

a · 0 = 0

a · S(b) = (a · b) + a

Proof. Fix a natural number a. If the current total is x, the next total should be x + a. By Theorem 13, x + a is a uniquely determined natural number for every x ∈ ℕ. By Theorem 11, this gives a function g: ℕ → ℕ with g(x) = x + a.

Now apply Theorem 12 with starting value 0 and update function g. It gives a unique function h: ℕ → ℕ satisfying

h(0) = 0

h(S(b)) = g(h(b)) = h(b) + a.

For the input pair (a, b), take the function h determined by a, then evaluate it at b. Each pair gives exactly one natural number. By Theorem 11, this rule defines a function from ℕ × ℕ to ℕ. Write its output h(b) as a · b. The two equations for h now read a · 0 = 0 and a · S(b) = (a · b) + a.

For uniqueness, suppose another operation satisfies the same equations. Fix its first input a. As the second input varies, the resulting function also starts at 0 and updates its value by adding a. By the uniqueness in Theorem 12, this function must be h. Thus the two operations agree on every input pair and have the same graph.

Computing 2 · 2

Keep the first input fixed at 2. The starting equation gives 2 · 0 = 0. Since 1 = S(0), the step equation gives

2 · 1 = (2 · 0) + 2 = 0 + 2 = 2.

The last equality uses Theorem 14. Now use 2 = S(1) to take one more step.

2 · 2 = (2 · 1) + 2 = 2 + 2.

We can finish using addition. Write 4 for S(3). By Theorem 13, 2 + 1 = S(2 + 0) = S(2) = 3. Applying the same rule again gives

2 + 2 = 2 + S(1) = S(2 + 1) = S(3) = 4.

Thus 2 · 2 = 4.

Theorem 19: Multiplication by Zero and One

For every natural number a,

a · 0 = 0 and 0 · a = 0.

a · 1 = a and 1 · a = a.

Proof. First consider 0 and 1 in the second position. The equation a · 0 = 0 is the starting equation from Theorem 18. Since 1 = S(0), one step gives

a · 1 = (a · 0) + a = 0 + a = a.

For 0 in the first position, use Theorem 7 to prove 0 · b = 0 for every b. The base case is 0 · 0 = 0. For the induction step, assume 0 · b = 0. The step equation tells us to add the first input, which here is 0. Thus

0 · S(b) = (0 · b) + 0 = 0 + 0 = 0.

Finally, use induction to prove 1 · b = b. The base case is 1 · 0 = 0. Assume 1 · b = b. This time the step equation tells us to add 1, so

1 · S(b) = (1 · b) + 1 = b + 1.

Our goal at this step is 1 · S(b) = S(b). To see why b + 1 equals the required value, write 1 = S(0) and use Theorem 13:

b + 1 = b + S(0) = S(b + 0) = S(b).

This completes the induction and proves all four equalities.
