De Morgan’s Laws for Set Difference

Assume Set A, B, C are the subsets of set U, and all complement sets in this page is relative to U. Based onDefinition of Set Difference， x ∈ A ∖ B if and only if x belongs to A AND x not belongs to B。 We use this definition andDe Morgan's Lawsto prove following theorems.

Substracting a Union Set

A ∖ (B ∪ C) = (A ∖ B) ∩ (A ∖ C)

Proof: Pick any x ∈ U。 x belongs to A ∖ (B ∪ C), if and only if x belongs to A, AND to the complement of B ∪ C. By De Morgan's first law:

(B ∪ C)c = Bc ∩ Cc。

Thus, x belongs to the left-hand side if and only if it belongs to A but to neither B nor C. Which is equivalent to both statement are true:

  • 1. x in A but not in B , which is x ∈ A ∖ B.
  • 2. x in A but not in C , which is x ∈ A ∖ C.

If these two statements are satisfied at the same time, that means x belongs to (A ∖ B) ∩ (A ∖ C)。 They have same elements, so they are equavalent.

Difference an Intersection Set

A ∖ (B ∩ C) = (A ∖ B) ∪ (A ∖ C)

Proof: Pick any x ∈ U。 By definition, x belongs A ∖ (B ∩ C), if and only if x belongs to A, AND x belongs to (B ∩ C)c。 By De Morgan's second law:

(B ∩ C)c = Bc ∪ Cc。

So, x belongs to left-hand side if and only if x belongs to A, AND at least one of B and C do not include x. That equivalent one of these statements is true:

  • 1. x in A but not in B , which is x ∈ A ∖ B。
  • 2. x in A but not in C , which is x ∈ A ∖ C。

At least one statement is true，which means x belongs to (A ∖ B) ∪ (A ∖ C). Two sets have completely same elements, so they are equivalent.
