Mathematical Induction

Suppose a statement holds for 0, and whenever it holds for a natural number, it also holds for its successor. Starting at 0, we can reach the conclusion for 1, then for 2, then for 3. What justifies the word "every" in "every natural number"?

Theorem 7: Mathematical Induction

Let P(n) stand for a condition on n written in the language of set theory. To prove that P(n) holds for every natural number n, it is enough to establish these two facts.

  1. Base case. P(0) holds.
  2. Induction step. For every k ∈ ℕ, if P(k) holds, then P(S(k)) holds.

In the induction step, we fix an arbitrary k ∈ ℕ and assume P(k). This assumption is called the induction hypothesis. Our goal in that step is P(S(k)).

Proof. Suppose both facts hold. By Axiom 2, we can form the set T of all natural numbers for which P holds. Its membership test is

n ∈ T ⇔ (n ∈ ℕ and P(n) holds).

The base case gives P(0). Since 0 ∈ ℕ, we have 0 ∈ T. Now take any k ∈ T. Then k ∈ ℕ and P(k) holds. The induction step gives P(S(k)). Also, S(k) ∈ ℕ because ℕ is inductive. Thus S(k) meets both conditions for membership in T.

We have shown that T contains 0 and contains the successor of each of its elements. Thus T is inductive. By Theorem 6, ℕ is contained in every inductive set, so ℕ ⊆ T. Every natural number therefore belongs to T, which means that P holds for every natural number.

Theorem 8: Predecessors of Natural Numbers

A natural number m is a predecessor of n if S(m) = n. For example, 2 is a predecessor of 3 because S(2) = 3. We will prove that 0 has no predecessor and that every nonzero natural number has exactly one.

Why does 0 have no predecessor? Recall that S(m) = m ∪ {m}. Since m ∈ {m}, we have m ∈ S(m). Thus every successor contains an element. Since 0 is empty, no successor equals 0.

To prove existence for nonzero natural numbers, use Theorem 7 with the following condition.

P(n) means "n = 0 or n has a predecessor".

  • Base case. P(0) holds because its first alternative is 0 = 0.
  • Induction step. Take any k ∈ ℕ. We need to show P(S(k)). Which natural number has successor S(k)? The number k itself. This proves the second alternative for S(k). In this example the step works even without using the hypothesis P(k).

By induction, P(n) holds for every n ∈ ℕ. If n ≠ 0, only the second alternative can hold, so n has a predecessor.

Could a number have two different predecessors? Suppose a and b are both predecessors of n. Then S(a) = n = S(b). Assume for contradiction that a ≠ b.

  • We have a ∈ S(a), so a ∈ S(b) = b ∪ {b}. Thus a ∈ b or a = b. Our assumption leaves a ∈ b.
  • Likewise b ∈ S(b), so b ∈ S(a) = a ∪ {a}. Thus b ∈ a or b = a. Our assumption leaves b ∈ a.

By Axiom 3, we can form D = {a, b}. By Axiom 8, this nonempty set must have a member with no element in common with D. Check its two members. The sets a and D share b, because b ∈ a and b ∈ D. The sets b and D share a, because a ∈ b and a ∈ D.

Neither member meets the condition required by Axiom 8. This contradiction rules out a ≠ b. Hence a = b, proving that the predecessor of a nonzero natural number is unique.
