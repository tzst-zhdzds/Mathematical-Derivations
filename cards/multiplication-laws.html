Laws of Multiplication

Throughout this card, a, b, and c are natural numbers, and S(b) means the successor of b. Recall the two rules that define multiplication.

a · 0 = 0

a · S(b) = (a · b) + a

Distributivity over Addition

a · (b + c) = (a · b) + (a · c)

For example, 3 · (2 + 4) means adding 3 a total of six times. The first two copies of 3 contribute 3 · 2, and the last four contribute 3 · 4. The law says that we can split the sum this way for any natural numbers a, b, and c.

Proof. Fix a and b. We use induction on c.

Base case. Let c = 0. On the left, b + 0 = b, so we get a · b. On the right, a · 0 = 0, so we also get a · b.

Induction step. Assume the law holds for c. We want to prove it with S(c) in place of c. Our goal is

a · (b + S(c)) = (a · b) + (a · S(c)).

Start on the left. By the definition of addition, b + S(c) = S(b + c). Now the second factor is a successor, so we can apply the definition of multiplication.

a · (b + S(c)) = a · S(b + c) = a · (b + c) + a.

By the induction hypothesis, we can replace a · (b + c) with (a · b) + (a · c). Then use the associative law of addition to group the last two terms.

((a · b) + (a · c)) + a = (a · b) + ((a · c) + a).

The expression (a · c) + a is exactly a · S(c) by definition. This gives the right side of our goal and completes the proof.

Commutativity of Multiplication

a · b = b · a

To compare a · S(b) with S(b) · a, we need to know what happens when the successor is the first factor. We also need a rule for zero as the first factor.

Lemma 1: Zero as the First Factor

0 · b = 0

Proof. Use induction on b. For b = 0, the definition gives 0 · 0 = 0. Now suppose 0 · b = 0. Then

0 · S(b) = (0 · b) + 0 = 0 + 0 = 0.

This proves the lemma for every b.

Lemma 2: A Successor as the First Factor

S(a) · b = (a · b) + b

For example, compare 4 · 3 with 3 · 3. Each sum has three terms. Changing each term from 3 to 4 adds one to each of the three terms, so the total increases by three. The lemma makes the same claim for any a and b.

Proof. Fix a and use induction on b.

Base case. For b = 0, the left side is S(a) · 0 = 0. The right side is (a · 0) + 0 = 0.

Induction step. Assume S(a) · b = (a · b) + b. Replacing b with S(b) gives the following goal:

S(a) · S(b) = (a · S(b)) + S(b).

Start on the left. By the definition of multiplication, moving from b to S(b) adds one more copy of the first factor, S(a). Then apply the induction hypothesis.

S(a) · S(b) = (S(a) · b) + S(a) = ((a · b) + b) + S(a).

By associativity of addition, we can group the last two terms as b + S(a). To see how this helps, use the definition of addition and then commutativity of addition:

b + S(a) = S(b + a) = S(a + b) = a + S(b).

Replace b + S(a) with a + S(b). Then group the first two terms.

(a · b) + (b + S(a)) = (a · b) + (a + S(b)) = ((a · b) + a) + S(b).

By definition, (a · b) + a = a · S(b). This gives (a · S(b)) + S(b), exactly the right side of our goal. The lemma follows by induction.

Proof of Commutativity

Fix a. We prove a · b = b · a by induction on b.

Base case. By definition, a · 0 = 0. By Lemma 1, 0 · a = 0. Therefore, a · 0 = 0 · a.

Induction step. Assume a · b = b · a. Our goal is a · S(b) = S(b) · a.

  1. By definition, a · S(b) = (a · b) + a.
  2. By the induction hypothesis, (a · b) + a = (b · a) + a.
  3. By Lemma 2, S(b) · a = (b · a) + a.

Both sides of our goal equal (b · a) + a. Therefore, a · b = b · a for all natural numbers a and b.

Corollary: Distributivity with the Sum on the Left

(a + b) · c = (a · c) + (b · c)

Proof. Use commutativity to move c to the left. Apply the distributive law proved above, then use commutativity on each product.

(a + b) · c = c · (a + b) = (c · a) + (c · b) = (a · c) + (b · c).

Associativity of Multiplication

(a · b) · c = a · (b · c)

Proof. Fix a and b. We use induction on c.

Base case. Let c = 0. On the left, (a · b) · 0 = 0. On the right, b · 0 = 0, so a · (b · 0) = a · 0 = 0.

Induction step. Assume (a · b) · c = a · (b · c). Our goal is

(a · b) · S(c) = a · (b · S(c)).

On the left, the first factor is the product a · b. Applying the definition of multiplication adds one more copy of that product. Then we use the induction hypothesis.

(a · b) · S(c) = ((a · b) · c) + (a · b) = a · (b · c) + (a · b).

On the right, first expand the inner product: b · S(c) = (b · c) + b. Now we can distribute a over that sum.

a · (b · S(c)) = a · ((b · c) + b) = a · (b · c) + (a · b).

Both sides give the same sum. By induction, (a · b) · c = a · (b · c) for all natural numbers a, b, and c.
