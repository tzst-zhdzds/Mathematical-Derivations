Laws of Multiplication

Suppose we add a + b to a running total at every step. We could also keep two totals, adding a to the first and b to the second. After c steps, does adding the two separate totals give the same result? This is what the first distributive law says.

In the formulas below, a · c + b · c means (a · c) + (b · c).

Theorem 20: Distributivity with a Sum on the Left

For all natural numbers a, b, and c,

(a + b) · c = a · c + b · c.

Proof. Fix a and b. Use Theorem 7 to induct on c, the number of steps.

Base case. When c = 0, the left side is (a + b) · 0 = 0 by Theorem 18. On the right, both products are 0, so their sum is 0 + 0 = 0 by Theorem 13.

Induction step. Assume (a + b) · c = a · c + b · c. To see what changes at the next step, give the two current totals short names: let p = a · c and q = b · c. Our assumption now reads (a + b) · c = p + q.

Start with the left side at S(c). By Theorem 18, we add one more copy of a + b. Using the induction hypothesis gives

(a + b) · S(c) = ((a + b) · c) + (a + b) = (p + q) + (a + b).

Our goal is to put a with p and b with q. First use Theorem 17 to regroup the sum until q + a appears inside parentheses.

(p + q) + (a + b) = p + (q + (a + b)) = p + ((q + a) + b).

By Theorem 16, q + a = a + q. Substitute this equality, then regroup using Theorem 17 again.

p + ((a + q) + b) = p + (a + (q + b)) = (p + a) + (q + b).

Now p + a = (a · c) + a = a · S(c) by Theorem 18. Likewise, q + b = (b · c) + b = b · S(c). Substituting these expressions gives exactly our goal:

(a + b) · S(c) = a · S(c) + b · S(c).

By induction, the equality holds for every c ∈ ℕ.

Theorem 21: Commutativity of Multiplication

For all natural numbers a and b,

a · b = b · a.

Proof. Fix a and use Theorem 7 to induct on b. In the base case, a · 0 = 0 and 0 · a = 0 by Theorem 19.

Induction step. Assume a · b = b · a. We want to show a · S(b) = S(b) · a. On the left, the successor is in the second input, so Theorem 18 applies directly. Then use the induction hypothesis:

a · S(b) = (a · b) + a = (b · a) + a.

On the right, the successor is in the first input. To use Theorem 20, write S(b) as a sum. This follows from Theorem 13:

b + 1 = b + S(0) = S(b + 0) = S(b).

Replace S(b) with b + 1, distribute, and use Theorem 19 to replace 1 · a with a.

S(b) · a = (b + 1) · a = (b · a) + (1 · a) = (b · a) + a.

Both sides equal (b · a) + a. This proves the induction step and hence the commutativity of multiplication.

Theorem 22: Distributivity with a Sum on the Right

For all natural numbers a, b, and c,

a · (b + c) = a · b + a · c.

Proof. By Theorem 21, we can exchange the two factors to put the sum on the left. Then Theorem 20 lets us distribute.

a · (b + c) = (b + c) · a = b · a + c · a.

Apply Theorem 21 to each product in the sum. Replacing b · a with a · b and c · a with a · c gives the required result.

Theorem 23: Associativity of Multiplication

For all natural numbers a, b, and c, we can change which multiplication is performed first while keeping the factors in the same order.

(a · b) · c = a · (b · c).

Proof. Fix a and b. Use Theorem 7 to induct on c.

Base case. When c = 0, the left side is (a · b) · 0 = 0. On the right, b · 0 = 0, so a · (b · 0) = a · 0 = 0. These equalities follow from Theorem 18.

Induction step. Assume (a · b) · c = a · (b · c). At S(c), our goal is

(a · b) · S(c) = a · (b · S(c)).

Start with the left side. In the step rule x · S(c) = (x · c) + x, take x = a · b. Then apply the induction hypothesis to the first term of the resulting sum.

(a · b) · S(c) = ((a · b) · c) + (a · b) = (a · (b · c)) + (a · b).

Now start with the right side. Inside the parentheses, Theorem 18 gives b · S(c) = (b · c) + b. This puts a sum in the second input of multiplication, so Theorem 22 applies.

a · (b · S(c)) = a · ((b · c) + b) = (a · (b · c)) + (a · b).

The two sides give the same sum. This proves the induction step, so multiplication is associative on ℕ.
