Natural Numbers

Zero and the Successor

We use sets to represent numbers. We write 0 for the empty set. By Theorem 1, there is exactly one empty set.

0 = ∅

Given any set x, Axiom 3 gives us the singleton {x}. We can now take the union of x and {x}. We call the result the successor of x and write S(x).

S(x) = x ∪ {x}

The left set contributes every element of x. The right set contributes its only element, x itself. Starting from 0, we give the first successors the names 1, 2, and 3.

1 = S(0) = ∅ ∪ {0} = {0} = {∅}

2 = S(1) = {0} ∪ {1} = {0, 1}

3 = S(2) = {0, 1} ∪ {2} = {0, 1, 2}

Look at the step from 1 to 2. The set 1 already contains 0. Taking its union with {1} keeps 0 and adds 1 itself. Since 1 = {∅}, another way to write 2 is {∅, {∅}}.

Inductive Sets

We call a set I inductive if it satisfies both conditions below.

  • 0 ∈ I.
  • For every x, if x ∈ I, then S(x) ∈ I.

By Axiom 6, at least one inductive set exists. Every such set contains 0. It must then contain S(0), which is 1. Since it contains 1, it must also contain S(1), which is 2.

These conditions tell us which elements must be included. They allow an inductive set to have other elements as well. Can we find an inductive set that is contained in every inductive set? This is what "least" means here.

Theorem 6: There Is a Unique Least Inductive Set

Proof. Choose one inductive set I. We will build a set N from the elements of I, then prove that it has the required properties.

First, consider the inductive subsets of I. The set I itself is one such subset. For each x in I, keep x exactly when it belongs to every inductive subset of I. By Axiom 2, the elements that pass this test form a set N.

x ∈ N ⇔ (x ∈ I and x belongs to every inductive subset of I).

Why is N inductive? Check the two conditions separately.

  • 0 belongs to I. Every inductive subset of I also contains 0 by definition. Thus 0 passes the test, so 0 ∈ N.
  • Suppose x ∈ N. Then x ∈ I, so S(x) ∈ I because I is inductive. Now take any inductive subset J of I. Since x ∈ N, we have x ∈ J. Since J is inductive, S(x) ∈ J as well. Thus S(x) belongs to I and to every inductive subset of I, so S(x) ∈ N.

Why is N contained in every inductive set? Take any inductive set K. Our test only mentioned subsets of I, so consider the intersection I ∩ K. It contains 0 because I and K both contain 0. If x ∈ I ∩ K, then x belongs to both sets. Both are inductive, so S(x) also belongs to both. Hence I ∩ K is inductive.

The intersection I ∩ K is a subset of I, so it is one of the sets used in our test. Every element of N therefore belongs to I ∩ K, and hence to K. This proves N ⊆ K for every inductive set K.

Finally, suppose M is also a least inductive set. Since M is inductive and N is least, N ⊆ M. Since N is inductive and M is least, M ⊆ N. By Theorem 2, N = M.

The Set of Natural Numbers

We call the unique least inductive set the set of natural numbers and write it as ℕ. A natural number is an element of ℕ. In particular, 0 ∈ ℕ, and whenever n ∈ ℕ, we also have S(n) ∈ ℕ.
