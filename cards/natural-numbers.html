Natural Numbers

Zero

We will build the natural numbers using sets, starting with zero. We define 0 to be the empty set.

0 = ∅

The Successor

In this construction, each natural number is a set. We begin with the empty set, which we call 0.

Given any set X, we define its successor, written as S(X), by taking the union of X and {X}.

S(X) = X ∪ {X}

The set X contributes its elements. The set {X} contributes one element: X itself. The result is again a set.

To build the natural numbers, start with 0 and apply this rule repeatedly. If n is the set we have reached, we take S(n) as the next number.

Building the First Few Numbers

We can do set 1 first. Start with set 0. It has no elements to keep. Adding element 0 itself gives a set whose only element is 0. We call this set 1.

set 1 = S(0) = 0 ∪ {0} = {0} = {∅}

This is the distinction we saw on the empty set card: Set 0 has no elements, while set 1 contains the empty set as its only element. Note: ∅ ≠ {∅}.

Next is set 2. Start with set 1 = {0}. We keep element 0 and add element 1 itself. We call the resulting set 2.

2 = S(1) = {0} ∪ {1} = {0, 1}

Next is set 3. Start with set 2 = {0, 1}. We keep element 0 and 1 and add element 2 itself.

3 = S(2) = {0, 1} ∪ {2} = {0, 1, 2}

In this construction, each number is the set of all the numbers that came before it. Applying the same rule once more gives 4 = {0, 1, 2, 3}.

We now have a rule for building the next number set at every step. What guarantees that there is a single set containing all the natural numbers? See next card!
