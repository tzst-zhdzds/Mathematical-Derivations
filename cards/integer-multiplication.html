Integer Multiplication

Repeating a Walk

A walk with record (2, 1) takes two forward steps and one backward step. Walking it twice gives the record (4, 2). In general, if we repeat the walk (a, b) a natural number n of times, the record is (an, bn). Here an means the natural-number product a · n.

What if we start with another record (u, v) for the same integer? By Theorem 26, we have a + v = u + b. Multiply both sides by n and distribute using Theorem 20:

an + vn = (a + v)n = (u + b)n = un + bn.

The two ends say exactly that (an, bn) ∼ (un, vn). Thus repeating either record n times gives the same integer. This also works when n = 0: both records then become (0, 0).

Using a Second Record as the Multiplier

Suppose the multiplier has record (c, d). For each of its c forward steps, take one copy of the first walk. For each of its d backward steps, undo one copy. This suggests repeating (a, b) first c times and then subtracting the effect of d copies:

[(ac, bc)] - [(ad, bd)].

To subtract the second class, switch its entries by Theorem 28 and add by Theorem 27. This gives the proposed product:

[(ac, bc)] + [(bd, ad)] = [(ac + bd, bc + ad)].

Theorem 29: Integer Multiplication Is Well-Defined

For any two integers, the following rule gives exactly one integer, whichever records we use to represent the inputs:

[(a, b)] · [(c, d)] = [(ac + bd, bc + ad)].

Proof. Every integer has a representative. For any two chosen representatives, the displayed formula produces a pair of natural numbers, so its class is an integer. It remains to check that changing representatives gives the same class.

First, keep (c, d) fixed and change the first record. We proved above that repeating equivalent records c times gives equal classes. The same holds for d repetitions. Therefore both inputs to the subtraction [(ac, bc)] - [(ad, bd)] stay the same as integers. Their difference stays the same too.

To handle the second record, look at what happens when we swap the two records in the formula. The entries in the following table are all natural numbers.

Input order Forward count Backward count
(a, b) then (c, d) ac + bd bc + ad
(c, d) then (a, b) ca + db da + cb

The forward counts agree because ca = ac and db = bd by Theorem 21. For the backward counts, the same law gives da + cb = ad + bc. By Theorem 16, this equals bc + ad. Thus swapping the input records gives exactly the same output record.

Now suppose we want to replace the second record by an equivalent one. Swap the two records, so the one we want to replace is first. Make the replacement, which preserves the output class by the first part of the proof. Then swap back. This proves that changing the second record also preserves the output class.

We can therefore change either representative, or change both one at a time. Each pair of integers determines exactly one output integer. By Theorem 11, the rule defines a function from ℤ × ℤ to ℤ.

Why Does (-1) · (-1) Equal One?

We write 1ℤ for [(1, 0)], the class of one forward step. The integer -1 is [(0, 1)]. Use (0, 1) for both records in Theorem 29:

(-1) · (-1) = [(0 · 0 + 1 · 1, 1 · 0 + 0 · 1)].

By Theorem 19, the forward count is 0 + 1 = 1, and the backward count is 0 + 0 = 0. The result is [(1, 0)], exactly one forward step.

(-1) · (-1) = 1ℤ.
