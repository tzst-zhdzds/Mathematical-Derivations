Commutativity and Associativity of Addition

Recall the definition of addition. For any natural numbers a and b, we have

a + 0 = a

a + S(b) = S(a + b)

Here S(b) means the successor of b. The second rule tells us what happens when we take the successor of the number on the right. Now we need to see what happens when we take the successor of the number on the left? We will use this Lemma later.

Lemma: A Successor on the Left

For all natural numbers a and b,

S(a) + b = S(a + b).

Proof. Fix any natural number a. We use induction on b.

Base Case. Let b = 0. On the left, S(a) + 0 = S(a). On the right, a + 0 = a, so S(a + 0) = S(a). Both sides equal S(a).

Induction step. Suppose S(a) + b = S(a + b). This is our induction hypothesis. We want to prove the same statement with S(b) in place of b. Our goal is

S(a) + S(b) = S(a + S(b)).

Start with the left side of our goal. Recall that the definition of addition gives x + S(y) = S(x + y) for any natural numbers x and y. Here, take x = S(a) and y = b. This gives

S(a) + S(b) = S(S(a) + b).

Inside the outer S, the induction hypothesis lets us replace S(a) + b with S(a + b). This gives S(S(a + b)). By definition, S(a + b) = a + S(b), so we get

S(S(a + b)) = S(a + S(b)).

Finally, S(a) + S(b) = S(S(a) + b) = S(S(a + b)) = S(a + S(b)). Inductive step success! So: S(a) + b = S(a + b).

By induction, S(a) + b = S(a + b) for every natural number b. Since a was arbitrary, the identity holds for all natural numbers a and b.

Theorem: Commutativity of Addition

For all natural numbers a and b, changing their order preserves the sum.

a + b = b + a

Proof. Fix any natural number a. We use induction on b.

Base Case. Let b = 0. By definition, a + 0 = a. On the addition card, we also proved that 0 + a = a. Therefore, a + 0 = 0 + a.

Induction Step. Suppose a + b = b + a. We want to show that a + S(b) = S(b) + a. Start on the left.

  1. By the definition of addition, a + S(b) = S(a + b).
  2. By the induction hypothesis, S(a + b) = S(b + a).
  3. The lemma gives S(b) + a = S(b + a). Reading that equality from right to left gives S(b + a) = S(b) + a.

a + S(b) = S(a + b) = S(b + a) = S(b) + a.

This proves the induction step. Therefore, a + b = b + a for all natural numbers a and b.

Theorem: Associativity of Addition

For all natural numbers a, b, and c, we can add a and b first, or we can add b and c first. The order of the numbers stays the same.

(a + b) + c = a + (b + c)

Proof. Fix any natural numbers a and b. We use induction on c.

Base Case. Let c = 0. On the left, adding 0 to a + b gives a + b. On the right, b + 0 = b, so a + (b + 0) also equals a + b.

Induction Step. Suppose (a + b) + c = a + (b + c). We want to prove the same equality with S(c) in place of c.

On the left, apply the definition of addition. Then use the induction hypothesis inside S:

(a + b) + S(c) = S((a + b) + c) = S(a + (b + c)).

Now look at the right side, a + (b + S(c)). First apply the definition to the inner sum, b + S(c). Then apply it to the outer sum:

a + (b + S(c)) = a + S(b + c) = S(a + (b + c)).

Both sides equal S(a + (b + c)), so the induction step holds. Therefore, (a + b) + c = a + (b + c) for all natural numbers a, b, and c.
