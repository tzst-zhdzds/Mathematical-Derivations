Laws of Addition

Does changing the order of two numbers change their sum? Our definition of addition treats the two inputs differently. In a + b, we start at a and take b successor steps. To prove that we can exchange the inputs, we first need to understand what happens when the starting number changes.

Theorem 15: A Successor in the First Input

By Theorem 13, a + S(b) = S(a + b). This tells us what happens when we take one more step. What happens if we keep the number of steps fixed and start at S(a) instead of a? For all natural numbers a and b, we claim that

S(a) + b = S(a + b).

Proof. Fix a natural number a. We use Theorem 7 to induct on b.

Base case. When b = 0, the left side is S(a) + 0 = S(a). On the right, a + 0 = a, so S(a + 0) = S(a). The two sides are equal.

Induction step. Assume S(a) + b = S(a + b). To write our goal, replace b with S(b) on both sides of that statement. We must show

S(a) + S(b) = S(a + S(b)).

Start with the left side. The step rule from Theorem 13 says x + S(y) = S(x + y) for any natural numbers x and y. Here the whole first input is x = S(a), and y = b. Substituting those values gives

S(a) + S(b) = S(S(a) + b).

Inside the outer S, we now see S(a) + b. Our induction hypothesis says this equals S(a + b). Thus the left side of our goal equals S(S(a + b)).

Now look at the right side of our goal, S(a + S(b)). The expression inside the outer S is a + S(b). By Theorem 13, it equals S(a + b). So the right side also equals S(S(a + b)).

This proves the induction step. Therefore S(a) + b = S(a + b) for all natural numbers a and b.

Theorem 16: Commutativity of Addition

Addition is commutative. This means that exchanging the two inputs leaves the sum unchanged. For all natural numbers a and b,

a + b = b + a.

Proof. Fix a and use Theorem 7 to induct on b.

Base case. We need a + 0 = 0 + a. By Theorem 13, a + 0 = a. By Theorem 14, 0 + a = a. Thus both sides equal a.

Induction step. Assume a + b = b + a. At the next input, our goal is

a + S(b) = S(b) + a.

On the left, the successor is in the second input. By Theorem 13,

a + S(b) = S(a + b).

On the right, the successor is in the first input. By Theorem 15,

S(b) + a = S(b + a).

The induction hypothesis gives a + b = b + a. Taking the successor of these equal numbers gives S(a + b) = S(b + a). This proves our goal. By induction, a + b = b + a for all a and b in ℕ.

Theorem 17: Associativity of Addition

Addition is associative. The order of the three inputs stays the same, and we can choose which sum to compute first. For all natural numbers a, b, and c,

(a + b) + c = a + (b + c).

Proof. Fix a and b. We use Theorem 7 to induct on c. This choice lets us apply the step rule for addition whenever c becomes S(c).

Base case. When c = 0, the left side is (a + b) + 0 = a + b. On the right, b + 0 = b, so a + (b + 0) = a + b. Both calculations use Theorem 13.

Induction step. Assume (a + b) + c = a + (b + c). Replacing c with S(c) gives our goal:

(a + b) + S(c) = a + (b + S(c)).

Start with the left side. In the step rule x + S(y) = S(x + y), take x = a + b and y = c. This gives

(a + b) + S(c) = S((a + b) + c).

Now work on the right side, starting inside the parentheses. First use b + S(c) = S(b + c). Then use the step rule again, this time with x = a and y = b + c.

a + (b + S(c)) = a + S(b + c) = S(a + (b + c)).

The two results are successors. What is inside each S? On the left we have (a + b) + c. On the right we have a + (b + c). These are equal by the induction hypothesis, so their successors are equal as well.

This proves the induction step. Therefore (a + b) + c = a + (b + c) for all a, b, and c in ℕ.
