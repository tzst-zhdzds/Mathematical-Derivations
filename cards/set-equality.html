Set equality

If every element of A is also an element of B, and every element of B is also an element of A, then the sets are equal. We write:

A = B

These two statements MUST be true at the same time!

Example: we have two sets A and B:

A = {orange, banana}
B = {banana, orange}

They have the same elements, so A = B. Also, the order of the elements doesn't matter.

Unequal Sets

We have a set C:

C = {orange, banana, apple}

Since apple ∈ C but apple ∉ A, the sets are not equal. We write:

A ≠ C

The symbol ≠ means “is not equal to.”
