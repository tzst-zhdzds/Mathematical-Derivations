Define sets

When we want to discuss a group of objects, we define the group as a set S. An object in a set is called an element. Notation: Set S = {element 1, element 2, element 3, ...}, where S is the name of the set, and objects in {} are its elements. Example: We have a fruit set: F = {apple, banana, orange, ...}

belong to and not belong to

If element 1 is in the set S, we could use: element 1 ∈ S

If element 20 is not in the set S, we could use: element 20 ∉ S
