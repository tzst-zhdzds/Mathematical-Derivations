ZFC Axioms

To reason about sets, we need some starting assumptions about sets themselves. We call these assumptions axioms.

We will start with an example of how to use an axiom, then look at what each of the other axioms lets us do.

The Language of Sets

In ZFC, our variables stand for sets. We take "set" and "is an element of" as basic ideas. A set can itself be an element of another set. In x ∈ A, both x and A are sets. The statement says that x is an element of A. Capitalization is only a naming convention.

x ∈ A

Read this as "x is an element of A" or "x belongs to A." And for its negate, we write x ∉ A as a shorter way to write ¬(x ∈ A).

A = B

Read this as "A and B are the same set." Two different letters can name the same object. We write A ≠ B when A and B are different objects.

Every object equals itself, so x = x is always true. If A = B, we can replace A with B in a statement without changing its truth value. For example, if x ∈ A and A = B, then x ∈ B.

Axiom 1: The Axiom of Extensionality

If A and B have exactly the same elements, then A = B. We can write this using the symbols from Basic Logic.

∀A ∀B ([∀x (x ∈ A ⇔ x ∈ B)] ⇒ A = B)

Read the statement from the outside in.

  • ∀A ∀B means that we may take any sets A and B.
  • ∀x (x ∈ A ⇔ x ∈ B) is the condition we must check. Every element of A belongs to B, and every element of B belongs to A.
  • ⇒ A = B gives the conclusion we may draw once we have established that condition.

Why Is the Empty Set Unique?

Suppose E and F are both sets with no elements. Could they be different sets? Pick any x. The statement x ∈ E is false, and x ∈ F is also false. From our truth table, an "if and only if" statement is true when both sides are false. Thus, for every x, we have

x ∈ E ⇔ x ∈ F.

By extensionality, E = F. We have proved that there can be at most one set with no elements. Our proof began with "suppose E and F are both sets with no elements." How do we know that even one such set exists?

Axiom 2: Separation and the Existence of the Empty Set

Start with a set A and a condition written in the language of set theory. Separation says that there exists a set containing exactly those elements of A that satisfy the condition.

To construct a set with no elements, start with any set A. We can do this because the first-order logic used by ZF assumes that there is at least one object, and in ZF every object is a set. Now keep an element x of A only if x ≠ x. (ZF is ZFC but without axiom of choice, you will see it later.)

Every object equals itself, so no element passes the test. Separation guarantees that the result of filtering A is still a set. We have therefore found a set with no elements.

Separation gives existence. Extensionality gives uniqueness. We can now call this set the empty set and give it a symbol.

∅

Theorem 1: There Is Exactly One Empty Set

By Axiom 2, there exists a set with no elements. By Axiom 1, any two sets with no elements are equal. Therefore, there is exactly one empty set.

Some presentations of ZF include the existence of the empty set as an explicit axiom. Here we derived it using Separation.

Axiom 3: Pairing

Given any sets a and b, Axiom 3 gives us a set whose elements are exactly a and b. If two sets both fit this description, they have exactly the same elements. By Axiom 1, they are equal. We write this unique set as {a, b}.

Taking b = a gives a set whose only element is a. We write it as {a}. A set with exactly one element is called a singleton.

For example, {∅} has one element, namely ∅. The empty set itself has no elements. We can tell them apart by checking whether ∅ belongs to each one.

∅ ∈ {∅} and ∅ ∉ ∅.

Suppose ∅ = {∅}. We know that ∅ ∈ {∅}. Replacing {∅} on the right with its equal, ∅, gives ∅ ∈ ∅. But the empty set has no elements. Therefore, ∅ ≠ {∅}.

Axiom 4: Union

Given a set F, there exists a set containing exactly those objects that belong to some member of F. To find them, look inside each member of F.

For example, Pairing gives us F = {A, B}. Its members are A and B. Looking inside them collects everything that belongs to A or to B, including anything that belongs to both. We call the resulting set the union of A and B and write A ∪ B.

x ∈ A ∪ B ⇔ (x ∈ A ∨ x ∈ B)

Axiom 5: Power Set

A set B is a subset of A if every element of B also belongs to A. We write this as B ⊆ A.

The Power Set Axiom says that for every set A, there exists a set whose elements are exactly all subsets of A. We call it the power set of A and write P(A).

B ∈ P(A) ⇔ B ⊆ A

Axiom 6: Infinity

Given a set x, Pairing lets us form {x}. Taking the union x ∪ {x} keeps every element of x and includes x itself as an element. We call the result the successor of x.

S(x) = x ∪ {x}

The Axiom of Infinity says that there exists a set I with both of the following properties.

  • ∅ belongs to I.
  • Whenever x belongs to I, its successor S(x) also belongs to I.

For example, since ∅ belongs to I, its successor must also belong to I. We can apply the same rule again to that successor. Later, we will use I to construct the set of natural numbers.

Axiom 7: Replacement

Suppose we have a set A and a rule expressed in the language of set theory. If the rule assigns exactly one output to each element of A, Replacement says that all the resulting outputs form a set.

For example, the rule might assign {x} to each x in A. Replacement lets us collect all those singletons into a set, even when the singletons themselves do not belong to A.

Separation and Replacement are called axiom schemas. Each describes a pattern. Substituting a particular allowed formula into the pattern gives an axiom.

Axiom 8: Foundation

A set is nonempty if it has at least one element. Foundation says that every nonempty set A has some element b such that b and A have no element in common.

For example, could a set x belong to itself? Suppose x ∈ x and form A = {x}. The set A is nonempty, so Foundation applies. Its only element is x, so x would have to be the element that has nothing in common with A.

But x ∈ x by our assumption, and x ∈ A because A = {x}. Thus x is an element common to both x and A. This contradiction shows that no set belongs to itself.

Axiom 9: The Axiom of Choice

The C in ZFC stands for Choice. Suppose F is a set and every member of F is nonempty. The Axiom of Choice says that there exists a single assignment that selects one element from each member of F. Later, we will call this assignment a choice function.

Why is this different from saying "pick any x" in a proof? When we proved uniqueness of the empty set, we considered an arbitrary x so that our reasoning would apply to every x. We only needed to compare the statements x ∈ E and x ∈ F.

Choice addresses a different question. For each member of F, we know that at least one element is available. Can all those selections be made together in one assignment, even if we have no particular selection rule in mind? The Axiom of Choice says yes.
