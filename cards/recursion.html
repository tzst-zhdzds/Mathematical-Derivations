Recursion on the Natural Numbers

Computing One Value from the Previous Value

Let X = {0, 1}. Define a function g: X → X by setting g(0) = 1 and g(1) = 0. Applying g switches the value.

Suppose we want a function f that records the value after each switch. Start with f(0) = 0. Once we know f(n), apply g to get the value at the next input.

f(S(n)) = g(f(n))

The two sides describe different steps. On the left, S(n) is the next input. On the right, f(n) is the current output, and g tells us what to do with that output.

f(1) = g(f(0)) = g(0) = 1

f(2) = g(f(1)) = g(1) = 0

f(3) = g(f(2)) = g(0) = 1

These calculations determine the first few values. What guarantees that the same instructions define a function on all of ℕ, with exactly one output at every input?

Theorem 12: Recursion on the Natural Numbers

Let X be a set, let a ∈ X, and let g: X → X be a function. There exists a unique function f: ℕ → X satisfying both equations below.

f(0) = a

f(S(n)) = g(f(n)) for every n ∈ ℕ.

Proof. Build the Graph

By Theorem 10, D = ℕ × X is a set. It contains every possible input-output pair. We want to find the pairs that the two equations force us to include.

What do the equations require of a graph? Consider the binary relations from ℕ to X that obey the following two rules.

  1. Include (0, a).
  2. Whenever (n, y) is included, also include (S(n), g(y)).

D itself obeys both rules. In particular, if (n, y) ∈ D, then S(n) ∈ ℕ and g(y) ∈ X, so (S(n), g(y)) ∈ D. Using Axiom 2, keep a pair in D exactly when it belongs to every subset of D that obeys both rules. Call the resulting set F.

F contains (0, a) because every such subset contains it. If (n, y) ∈ F, then every such subset contains (n, y), so every one also contains (S(n), g(y)). Thus the next pair belongs to F as well. This proves that F obeys both rules. By construction, F is contained in every subset that obeys them.

Where Can a Pair in F Come From?

We know how to go forward from a pair in F. To prove that an input cannot have two outputs, we also need to go backward. Could F contain an extra pair that never came from either rule?

By Axiom 2, form a subset E of F by keeping only the following pairs:

  • the starting pair (0, a),
  • any pair of the form (S(k), g(v)) for some (k, v) ∈ F.

E still obeys both rules. It contains (0, a). If (n, y) ∈ E, then (n, y) ∈ F because E ⊆ F. Its next pair (S(n), g(y)) therefore belongs to F and is exactly the kind of pair we kept in E.

Since E obeys both rules, the construction of F gives F ⊆ E. We already have E ⊆ F, so Theorem 2 gives F = E. Now we know that every pair in F is either the starting pair or the next pair obtained from some pair in F.

Why Does Each Input Have Exactly One Output?

We use Theorem 7 to prove that for every n ∈ ℕ, exactly one y ∈ X satisfies (n, y) ∈ F.

Base case. We have (0, a) ∈ F. Could another pair in F start with 0? Every pair produced by the step rule starts with a successor S(k). By Theorem 8, no successor equals 0. Thus the starting pair is the only pair in F with first entry 0.

Induction step. Assume that y is the unique output at n. Since (n, y) ∈ F, the step rule gives (S(n), g(y)) ∈ F. This proves that S(n) has at least one output.

To check uniqueness, take any pair (S(n), w) ∈ F. Since S(n) ≠ 0, it cannot be the starting pair. By F = E, it must have come from some pair (k, v) ∈ F. Thus

(S(n), w) = (S(k), g(v)).

By Theorem 9, the first entries agree, so S(n) = S(k). By Theorem 8, this number has a unique predecessor, so k = n. Now (k, v) ∈ F tells us that v is an output at n. The induction hypothesis gives v = y. Comparing the second entries of the displayed pairs gives w = g(v) = g(y). Thus S(n) has exactly one output.

By induction, F gives exactly one output for every natural number. It is therefore the graph of a function f: ℕ → X. Its starting pair gives f(0) = a, and its step rule gives f(S(n)) = g(f(n)).

Why Is the Function Unique?

Suppose h: ℕ → X satisfies the same two equations. We prove by Theorem 7 that h(n) = f(n) for every n ∈ ℕ. At 0, both functions have the value a. If h(n) = f(n), applying g to these equal values gives

h(S(n)) = g(h(n)) = g(f(n)) = f(S(n)).

Thus h and f agree at every input. Their graphs contain exactly the same ordered pairs, so Axiom 1 gives h = f.
