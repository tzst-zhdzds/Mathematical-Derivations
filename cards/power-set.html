Power Sets

What Belongs to a Power Set?

Let A be a set. By Axiom 5, there exists a set whose elements are exactly the subsets of A. By Axiom 1, any two sets with exactly these elements are equal. We call this unique set the power set of A and write P(A).

B ∈ P(A) ⇔ B ⊆ A

This gives us a test. To decide whether B belongs to P(A), look at the elements of B and ask whether every one of them belongs to A.

What happens if we use A itself as the candidate? Every element of A belongs to A, so A ⊆ A. The membership test therefore gives A ∈ P(A).

The Power Set of the Empty Set

Which sets belong to P(∅)? By Theorem 3, the empty set is a subset of every set. In particular, ∅ ⊆ ∅, so ∅ ∈ P(∅).

Could anything else belong to P(∅)? Suppose B ∈ P(∅). Then B ⊆ ∅. If B had an element x, the subset condition would give x ∈ ∅, which is impossible. Thus B has no elements. By Theorem 1, B = ∅.

We have found exactly one element of P(∅), namely ∅. Placing that element inside braces gives the power set:

P(∅) = {∅}.

The Power Set of {∅}

Now start with A = {∅}. This time A has an element, namely ∅. A subset B of A can contain only elements found in A. There are two possibilities.

  • If ∅ ∉ B, then B contains nothing at all, so B = ∅.
  • If ∅ ∈ B, then ∅ is its only element. By Axiom 1, B = {∅}.

Both candidates really are subsets of A. The empty set is a subset of A by Theorem 3, and {∅} is A itself. Collecting these two subsets gives

P({∅}) = {∅, {∅}}.

Read the right side from the outside in. The outer braces enclose the elements of the power set. The first element is ∅. The second element is {∅}.

Theorem 4: Inclusion of Power Sets

For any sets A and B,

A ⊆ B ⇔ P(A) ⊆ P(B).

Proof, forward direction. Assume A ⊆ B. To prove P(A) ⊆ P(B), take any X ∈ P(A). We must show X ∈ P(B). By the membership test, X ⊆ A.

Take any element x of X. Since X ⊆ A, we have x ∈ A. Since A ⊆ B, we then have x ∈ B. Thus every element of X belongs to B, so X ⊆ B. The membership test now gives X ∈ P(B). This proves P(A) ⊆ P(B).

Proof, reverse direction. Assume P(A) ⊆ P(B). This tells us that every element of P(A) belongs to P(B). Which element of P(A) should we use? Our goal is A ⊆ B, so we want to show that A itself belongs to P(B).

Since A ⊆ A, we have A ∈ P(A). Our assumption then gives A ∈ P(B). By the membership test for P(B), this means exactly that A ⊆ B. This proves the reverse direction.
