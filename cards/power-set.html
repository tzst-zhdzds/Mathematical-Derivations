Power Set

Define a set P is the set of all subsets of a set A, called power set of A, written as P(A). Or in other word, for any set B, we have:

B ∈ P(A) ⇔ B ⊆ A

How we find all subsets?

Assume A = {a, b} , a not equals b, we can list all subsets by amount of elements in the set:

  • 0 elements, get ∅;
  • 1 elements, get {a} or {b};
  • 2 elements, get {a, b}.

These already include all possible subsets for A, so A's power set which is:

P(A) = {∅, {a}, {b}, {a, b}}

Note: {a} is one of A's subset, so {a} ⊆ A. By definition, in P(A), set {a} is one element of P(A), so written as {a} ∈ P(A).

Also, We already prove that empty set is a subset for every set, And every set is the subset of itself, so we have:

∅ ∈ P(A) , A ∈ P(A).
