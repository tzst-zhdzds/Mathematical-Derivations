Ordered Pairs and Cartesian Products

Ordered Pairs

The ordered pair (a, b) recorded two objects IN ORDER: First term is a, and second term is b. Note: if a ≠ b, then ordered pair (a, b) ≠ ordered pair (b, a), because they have different order!

To decide two ordered pair is equal or not, we have to compare each term! The order DOES matter! Two ordered pair are equal if and only if each term is match up.

(a, b) = (c, d) ⇔ a = c AND b = d

Cartesian Products

Given two sets A and B, pick one element from A as first term in ordered pair, pick one element from B as second term in ordered pair, If a set consists of all ordered pairs (x, y) with x ∈ A and y ∈ B, it's called Cartesian Products of A and B, written as A × B.

(x, y) ∈ A × B ⇔ x ∈ A AND y ∈ B

For example: Assume A = {1, 2}, B = {3, 4}. When pick element 1 as first term, we could choose element 3 or 4 as second term; same for element 2. List all possible ordered pair, we get:

A × B = {(1, 3), (1, 4), (2, 3), (2, 4)}
