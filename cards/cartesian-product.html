Ordered Pairs and Cartesian Products

How Can a Set Record Order?

The sets {a, b} and {b, a} have exactly the same elements, so they are equal by Axiom 1. Suppose we want to record which entry came first. We give the first entry its own singleton and define the ordered pair (a, b) by

(a, b) = {{a}, {a, b}}.

By Axiom 3, we can form {a} and {a, b}, then apply the same axiom to these two sets. The outer braces collect the two inner sets. If b = a, the inner sets coincide, so (a, a) = {{a}}.

Theorem 9: Equality of Ordered Pairs

(a, b) = (c, d) ⇔ (a = c and b = d).

Proof. Suppose (a, b) = (c, d). First look for an element that belongs to every inner set in {{a}, {a, b}}. The element a does. It is the only one that can, because anything belonging to every inner set must belong to {a}. By the same reasoning, c is the unique element common to every inner set in {{c}, {c, d}}. The two outer sets are equal, so their unique common element is the same. Thus a = c.

Substitute a for c. The equality now reads

{{a}, {a, b}} = {{a}, {a, d}}.

  • If b = a, the left side has only one member, {a}. The set {a, d} on the right must therefore equal {a}. Since d belongs to {a, d}, this gives d = a = b.
  • If b ≠ a, then {a, b} differs from {a} because it contains b. It must also be a member of the right side. Its only possible match is {a, d}. Thus b belongs to {a, d}. Since b ≠ a, we get b = d.

Conversely, if a = c and b = d, substituting these equal entries into {{a}, {a, b}} gives {{c}, {c, d}}. This proves the reverse direction.

Cartesian Products

Given sets A and B, we want to collect all ordered pairs with a first entry from A and a second entry from B. We call this set the Cartesian product of A and B and write A × B.

For example, let a and b be distinct, and take A = {a, b} and B = {a}. The first entry can be a or b. The second entry must be a. In the reverse product, the first entry must be a instead.

A × B = {(a, a), (b, a)}

B × A = {(a, a), (a, b)}

By Theorem 9, (b, a) differs from both pairs in B × A because their first entries differ. Thus A × B and B × A are different sets in this example.

Theorem 10: The Cartesian Product Exists

For any sets A and B, there is a unique set whose elements are exactly the ordered pairs with first entry in A and second entry in B.

Proof. To use Axiom 2, we need a set to select from. Where can we find every pair we want? Start with the union U = A ∪ B. Take x ∈ A and y ∈ B. Then x and y both belong to U.

  1. The inner sets {x} and {x, y} are subsets of U. By the definition of a power set, both are elements of P(U).
  2. The members of (x, y) are precisely those inner sets. Each belongs to P(U), so the whole ordered pair is a subset of P(U). It is therefore an element of P(P(U)).

(x, y) ⊆ P(U), so (x, y) ∈ P(P(U)).

By Axiom 5, we can form P(U) and then P(P(U)). From P(P(U)), keep an element z exactly when there exist x ∈ A and y ∈ B such that z = (x, y). By Axiom 2, the selected elements form a set. Every desired pair was available, and every selected element is such a pair.

By Axiom 1, these elements determine a unique set. This is A × B. By Theorem 9, equal pairs have equal entries, so we can test membership directly.

(x, y) ∈ A × B ⇔ (x ∈ A and y ∈ B).
