Subsets

Definition

Let A and B be sets. We say that A is a subset of B if every element of A also belongs to B. We write A ⊆ B.

A ⊆ B ⇔ ∀x (x ∈ A ⇒ x ∈ B)

For example, take distinct sets a and b. By Axiom 3, we can form A = {a} and B = {a, b}. The only element of A is a, and a belongs to B. Therefore, A ⊆ B.

Does B ⊆ A also hold? To test this direction, start with an element of B. The element b belongs to B, but it does not belong to A because the only element of A is a and b ≠ a. This one counterexample shows that B ⊆ A is false.

Theorem 2: Equality by Mutual Inclusion

Two sets are equal if and only if each is a subset of the other.

A = B ⇔ (A ⊆ B ∧ B ⊆ A)

Proof, forward direction. Assume A = B. If x ∈ A, replacing A with B gives ∀x ∈ B. This proves A ⊆ B. Likewise, if ∀x ∈ B, replacing B with A gives x ∈ A. This proves B ⊆ A.

Proof, reverse direction. Assume A ⊆ B and B ⊆ A. Pick any x. Each inclusion gives us one implication about this same x.

  • From A ⊆ B, we get x ∈ A ⇒ x ∈ B.
  • From B ⊆ A, we get x ∈ B ⇒ x ∈ A.

Together, the two implications give x ∈ A ⇔ x ∈ B. Since x was arbitrary, A and B have exactly the same elements. By Axiom 1, A = B. This proves the reverse direction.

Theorem 3: The Empty Set Is a Subset of Every Set

∀A (∅ ⊆ A)

Proof. Let A be any set. By the definition of a subset, our goal is to prove the following statement.

∀x (x ∈ ∅ ⇒ x ∈ A)

When would this fail? There would have to be an x for which x ∈ ∅ is true and x ∈ A is false. By Theorem 1, ∅ is the unique set with no elements. Thus x ∈ ∅ is false for every x. The implication holds for every x, so ∅ ⊆ A.

Membership and Inclusion

Take A = ∅ in Theorem 3. We now have two statements about the same set:

∅ ⊆ ∅

∅ ∉ ∅

The first statement asks whether every element of the set on the left belongs to the set on the right. There is no element that could violate this condition.

The second statement asks whether the empty set itself appears as an element inside the empty set. It has no elements at all, so the answer is no.
