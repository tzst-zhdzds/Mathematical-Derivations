Subsets

If every element of A is also an element of B, we say that A is a subset of B. We write:

A ⊆ B

The symbol ⊆ represents "Set A is a subset of Set B". Note: an element ∈ B may not belong to A!

For example, we could have:

A = {apple}
B = {apple, banana}

The only element of A is apple, which also belongs to B. Therefore:

A ⊆ B

Also, for any Set A any element ∈ A also ∈ A, obviously, so：

A ⊆ A

Next, we want to prove: Two sets are equal if and only if they are subsets of each other, written as：

A = B ⇔ (A ⊆ B AND B ⊆ A)

The symbol ⇔ means “if and only if”, sometimes written as "iff", it means you can prove from left to right AND right to left. So, we need to prove both sides.

Proof:

Assume A = B. Want to show: (A ⊆ B AND B ⊆ A)

Based on the definition of set equality, A = B means Set A and Set B have the same elements. So, obviously, every element in Set A is also in Set B, and vice versa.

Next, assume A ⊆ B AND B ⊆ A.

So the number of elements in A is less than or equal to B, since A ⊆ B; also, the number of elements in B is less than or equal to A, by B ⊆ A; so the number of elements in A must be equal to the number of elements in B. Then, since A ⊆ B, every element of A belongs to B. Since B ⊆ A, every element of B belongs to A. Therefore, A and B have exactly the same elements. By the definition of set equality, A = B.

Both directions have been proved, so:

A = B ⇔ (A ⊆ B AND B ⊆ A)
